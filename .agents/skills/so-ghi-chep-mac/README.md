# Skill Codex cho khách dùng Mac

Mở cả thư mục dự án `codex/mac-customer-test` trong Codex. Skill nằm tại `.agents/skills/so-ghi-chep-mac/SKILL.md`; có thể gọi trực tiếp bằng `$so-ghi-chep-mac` khi hỏi cách cài, mở, quét PDF hoặc xử lý lỗi.

Nếu muốn dùng skill ở mọi dự án, chép nguyên thư mục `so-ghi-chep-mac` vào `~/.agents/skills/` trên Mac rồi mở phiên Codex mới. Không chép `.local/`, `inbox/` hoặc API key cùng skill.

Skill là hướng dẫn cho Codex; ứng dụng Sổ ghi chép vẫn tự chạy bằng `Mo-So-Ghi-Chep-Mac.command` và không dùng token Codex để xử lý PDF.
